VTVSHOP-255_IS: Cập Nhật Trạng Thái Subtask

done Anthropic · Claude Opus 5.5
AWS · off Kubernetes · off ✓ 4/4
⑂ feat/255-notify-email 131 28k/1M tmdt Normal

Mô hình: session là một hàng tab ngang hàng — mỗi tab là một "task" có loại

  1. Tab Trao đổi (loại discuss): transcript + composer tương tác với model — tab đầu tiên, pin, không đóng. Về sau strip có thể nhận thêm loại tab khác (terminal, preview…) mà không đổi khung.
  2. Mỗi trang web = một tab browser ngang hàng, favicon + title + × thật. Bấm link trong transcript (mode 'app') → tab mới focus luôn — thử bấm link PR trong khung chat.
  3. Agent tự mở tab → tab xuất hiện với spinner + chấm activity, không chiếm focus — thay vai trò auto-PiP. Nút "Giả lập agent mở tab" để xem.
  4. Navbar (back/forward/URL/⋯) chỉ hiện khi tab browser active; tab discuss không có navbar — đúng kiểu browser: thanh địa chỉ thuộc về tab web.
  5. View Browser dock 3 mép vẫn giữ cho side-by-side; browserAutoPip default → off, PiP chỉ mở thủ công (⋯ / ⇧⌘B).
  6. Header gộp một hàng: chips ngữ cảnh (task · SSH · AWS/k8s · todo · bookmark — hiện là SessionContextStrip một row riêng đầu chat) dời lên header, bù lại chiều cao mà tab bar chiếm. Hẹp quá thì chip tràn vào popover ⋯.
  7. Overflow → strip scroll ngang, × hiện khi hover/active; + = tab trắng + autofocus ô URL.

Wireframe mô phỏng bố cục + tương tác, không phải pixel cuối — màu/typography theo token useTheme() khi implement. Điểm chạm code: SessionDetail.vue (tab bar + vùng content), useEmbeddedBrowser.ts (mode pin theo tabId), useLinkOpen.ts (mở tab mới), useBrowserPip.ts (tắt auto), BrowserNavBar.vue (dùng lại trong content tab).
